# 模型驱动的数据需求规范 V1.0

**日期**: 2026-07-24
**来源**: R_eff 分解 + v0.1 数据审计

---

## 一、核心原则

数据采集的优先级由参数在 R_eff 中的**方差贡献**决定：

\[
R_{\text{eff}} \approx \beta \cdot \bar{k}_{\text{eff}} \cdot \sigma(\alpha_0 + \alpha_1|\bar{o}| + \alpha_2\bar{h} + \alpha_3\bar{\Gamma} - \alpha_4\bar{f} - \alpha_5\bar{c})
\]

参数的方差贡献 = 该项在 R_eff 中的偏导数 × 该参数的群体异质性。

**排序结果**：β > α₁ > k̄_eff > α₀ > α₃ > α₂ > α₄ > α₅ > 其余 21 个参数。

## 二、参数-数据映射表

### P0 参数（必须校准，解释 >80% 方差）

| 参数 | 含义 | R_eff 角色 | 需要的数据 | v0.1 状态 | 最小需求 |
|------|------|-----------|----------|:---:|------|
| **β** | 基础传播率 | 线性缩放 R_eff | 转发/回复级联边 + 时延 | ❌ 0条转发边 | ≥500条边，≥2层深度 |
| **α₁** | 观点极端性驱动 | P(E→A) 内 | 同一agent的公开立场 + 活跃/沉默标签 | ⚠️ 732 agents但仅14个≥3帖 | ≥50 agents×≥3时间窗 |
| **k̄_eff** | 有效平均度 | 线性缩放 R_eff | 关注/粉丝关系 或 互动网络 | ⚠️ 2171条回复边(无转发) | G_s ≥500节点 |

### P1 参数（应校准，解释 10-20% 方差）

| 参数 | 含义 | R_eff 角色 | 需要的数据 | v0.1 状态 | 最小需求 |
|------|------|-----------|----------|:---:|------|
| **α₀** | 基线激活率 | P(E→A) 截距 | 暴露者中激活的比例 | ⚠️ E不可观测 | 代理：reply立即跟随exposure的比例 |
| **α₃** | 意见气候权重 | P(E→A) 内 | 每个agent的本地气候 Γ_i + 激活决策 | ❌ 需G_o + 邻域活跃表达 | G_o ≥500节点 + 每节点≥3活跃邻居 |
| **α₂** | 情绪唤醒权重 | P(E→A) 内 | 情绪标注 + 随后的激活行为 | ⚠️ arousal_score存在但单一快照 | 每个agent≥2时间窗的情绪标签 |

## 三、v0.1 数据能做什么和不能做什么

### 能做的（事件级聚合建模）

1. **事件级传播曲线**：从 time_window + observed_active 可以得到 A(t) 时间序列
2. **公开立场分布**：805 条帖文的 stance 标签 → |ō| 的粗略估计
3. **情绪分布**：arousal_score → h̄ 的粗略估计
4. **网络规模估计**：732 agents + 2171 reply edges → k̄ 的下界估计
5. **冲击时间线**：97 篇政府文档（但时间戳问题严重）
6. **暴露代理**：neighbor_active_count 作为 Ẽ 的代理

### 不能做的（个体级参数估计）

1. **P(E→A) 估计**：E 不可观测 + agent 轨迹稀疏（14 agents ≥3帖）
2. **β 校准**：无转发边，无法追踪级联
3. **α₁ 校准**：无法区分"观点极端→更多表达"vs"更多表达→更极端"
4. **κ 计算**：information_flow_view 不完整（无转发方向）
5. **R_eff 经验估计**：缺少级联数据和个体转移链

## 四、最小数据采集的优先级路线

基于以上差距分析，建议按以下顺序进行定向采集：

### 第一步：转发级联（解锁 β + k̄_eff）

**操作**：对 v0.1 中 shared_count>0 的 271 条帖子运行 cascade collector。

**已有基础设施**：
- Weibo cookies 已提取（`data/cache/weibo_cookies.json`）
- `WeiboCascadeCollector` 已实现（`tibet_collector/collectors/weibo_cascade.py`）
- Repost API 已验证（top post 有 2926 次转发）

**预期产出**：≥500 条转发边，≥2 层深度 → 可以估计 β 的下界

**所需时间**：2-3 天（API 速率限制 1 req/3s）

### 第二步：Agent 轨迹增密（解锁 α₁ + α₃）

**操作**：对 200-agent panel（已通过 `identify_seeds.py` 选定）进行定向采集。

**策略**：
- 采集每个 panel agent 的全部历史帖文（而非仅关键词命中）
- 使用 `weiboSpider` 或 MediaCrawler 的 user timeline API
- 每 agent 目标 ≥10 条帖文

**预期产出**：200 agents × ≥10 时间窗 → 可以估计个体级转移概率

**所需时间**：1-2 周

### 第三步：冲击时间线（解锁 r₁ + Shock(t)）

**操作**：修复时间戳 + 补充事件时间线。

**已有**：government runner 已实现 6 层日期提取，confidence 100% B 级。
**待做**：为 TIB-2025-001 手动构建关键事件时间线（地震日、官方通报日、救援节点）。

**所需时间**：2-3 天

## 五、从现有数据可直接计算的量

| 量 | 公式 | v0.1 计算 | 用途 |
|------|------|:---:|------|
| A(t) | Σ 𝟙[observed_active=1] per window | ✅ | 传播曲线基线 |
| D(t) | Σ 𝟙[previously_active=1 ∧ observed_active=0] | ✅ | 沉默群体规模 |
| reactivation rate | reactivated / (previously_active) | ✅ | r₀+r₃h̄ 的粗略估计 |
| Ê_i(t) | neighbor_active_count | ✅ | 暴露代理（非真实E） |
| shock timeline | gov doc count per window × shock_intensity | ⚠️ | Shock(t) 的粗略代理 |
| |ō|| mean(abs(stance_score)) | ✅ | α₁|ō| 的输入 |
| h̄ | mean(arousal_score) | ✅ | α₂h̄ 的输入 |
| Γ̄ (approximate) | 同社区内 stance 一致性 | ⚠️ | 需要社区检测（有G_o可做） |
| k̄ | mean degree of reply graph | ✅ | k̄_eff 的下界 |
| observed P(A→D) | 1 - active_next / active_current | ⚠️ | 需要 ≥2 时间窗的 agent 轨迹 |
| observed P(D→A) | reactivated / previously_active | ⚠️ | 同上 |

## 六、R_eff 从 v0.1 的上下界估计

即使数据不完备，也可以给出 R_eff 的合理范围：

**下界**（最保守假设）：
- β_min ≈ 0.05（从 reply 图密度估计）
- |ō| ≈ 0.3（informational + neutral_observer 占 67%）
- h̄ ≈ 0.45（平均 arousal）
- σ(α₀ + α₁|ō| + α₂h̄) ≈ σ(-2.5 + 1.5×0.3 + 2.0×0.45) = σ(-1.15) ≈ 0.24
- R_eff_min ≈ 0.05 × k̄ × 0.24

**上界**（最乐观假设）：
- β_max ≈ 0.15（从 high-engagement seeds 的 shared_count 推断）
- |ō| ≈ 0.6（只看 emotional_outburst + support/oppose 群体）
- h̄ ≈ 0.65
- σ(-2.5 + 1.5×0.6 + 2.0×0.65) = σ(-0.30) ≈ 0.43
- R_eff_max ≈ 0.15 × k̄ × 0.43

**k̄ 的估计**：
- Reply graph: 732 nodes, 2171 edges → k̄_reply ≈ 3.0（下界）
- 实际关注网络 k̄ 通常远大于互动图：5 ≤ k̄ ≤ 50
- 假设 k̄ ∈ [3, 20]（社交媒体事件级网络的典型范围）

**R_eff 范围**：
- R_eff_min ≈ 0.05 × 3 × 0.24 = **0.036**
- R_eff_max ≈ 0.15 × 20 × 0.43 = **1.29**

这个范围跨越了临界值 1——意味着**无法从 v0.1 确定传播是增长还是衰减**。需要转发级联数据来收窄 β 和 k̄ 的估计。

## 七、校准策略

### 7.1 两阶段校准

**阶段 1**：事件级聚合校准（立即可行）

1. 从 A(t) 曲线估计 β × k̄_eff × P̄_activate 的复合值
2. 从公开立场分布估计 |ō| 和 Γ̄
3. 用 shock 时间线估计 r₁ 的阶数
4. 产生 R_eff 的上下界

**阶段 2**：个体级校准（需补充数据后）

1. 从级联深度分布估计 β（用极大似然）
2. 从 agent 面板的转移矩阵估计 α₀, α₁, α₃
3. 从活跃持续时间估计 γ₀, γ₁
4. 用 MCMC 或变分推断产生参数后验
5. 按事件留一验证

### 7.2 可识别性先决条件

基于 validation.py 的 identifiability 测试框架，每个参数的可识别性需要：

| 参数 | 可识别条件 | 当前满足？ |
|------|----------|:---:|
| β | ≥100 条级联边，≥2 层深度 | ❌ |
| α₁ | ≥50 agents 有 ≥3 次 stance 观测 | ❌ |
| α₀ | ≥30 个观测到的 E→A 转移 | ❌ (E不可观测) |
| γ₀ | ≥50 次 A→D 转移 | ⚠️ |
| r₁ | ≥2 次冲击事件 + 前后 A 计数 | ⚠️ (时间戳问题) |
| λ_spiral | 需要极端参数才能识别（见沉默螺旋实验） | ❌ |

## 八、总结：从方程到数据的一对一追溯

```
R_eff = ρ(M)  ←需要←  β  ←需要←  转发级联数据
                        k̄_eff  ←需要←  网络构建（关注/互动图）
                        P(E→A)  ←需要←  α₀,α₁|o|,α₂h,α₃Γ
                                  ←需要←  agent轨迹(≥3时间窗)
                                  ←需要←  stance标签(每帖)
                                  ←需要←  arousal标签(每帖)
                                  ←需要←  社区检测(G_o构建)
            ←验证←  A(t)曲线 ←需要← observed_active时间序列
            ←验证←  二次高峰 ←需要← Shock(t)时间线
```

**当前 v0.1 能支撑的**：事件级 R_eff 上下界估计 + 参数阶数约束
**需要补充的**：转发级联数据（β） + agent面板轨迹（α₁,α₃） + 精确冲击时间线（r₁）
