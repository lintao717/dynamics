# V1.2 Data Contract

## Canonical Fields

| Field | Type | Description |
|-------|------|-------------|
| `case_id` | `str` | Unique case identifier (equals root post_id) |
| `source_dataset` | `str` | Origin dataset ("CHECKED", "CED", ...) |
| `root.post_id` | `str` | Root microblog ID |
| `root.user_id` | `str` | Root author (hashed) |
| `root.timestamp` | `datetime` | Root post time (timezone-aware UTC) |
| `root.text` | `str` | Root post content |
| `root.label` | `str\|None` | Case label ("fake", "real", etc.) |
| `root.expert_analysis` | `str\|None` | Expert annotation |
| `interaction.kind` | `InteractionKind` | "comment", "repost", or "interaction" |
| `interaction.user_id` | `str` | Interacting user (hashed) |
| `interaction.timestamp` | `datetime` | Interaction time (timezone-aware UTC) |

## Time-Window Semantics

- Step 0 = root timestamp exactly.
- Step k (k ≥ 1): ((k-1) * Δt, k * Δt] after root.
- `TimeGrid.step_of(ts)` uses `ceil(hours / step_hours)`.

## State Mapping

| Real Data | Simulation State |
|-----------|-----------------|
| Root author | `z=A`, `m=1` |
| All other users | `z=U`, `m=0` |
| E state | Latent (never directly observed) |
| Private opinion `o` | Latent (sampled from prior) |
| Public expression `o_hat` | `NaN` for non-root (no text labels) |

## Network Direction

- `G[dst, src] > 0`: source `src` influences receiver `dst`.
- Root→user edges: `G[user_idx, root_idx]`.

## Three Replay Modes

| Mode | G_s Construction | Scientific Role |
|------|-----------------|-----------------|
| `broadcast` | Zero matrix | Primary evaluation |
| `cumulative_interaction` | Root→user after first action | Secondary mechanism |
| `oracle_static` | All edges from step 0 | Upper-bound sensitivity (not causal) |

## Missing-Data Rules

- Missing stance → `NaN` with `observation_masks["stance"] = False`.
- Missing arousal → `NaN` with `observation_masks["arousal"] = False`.
- Never convert missing to 0.

## Parameter Identifiability (CHECKED)

- **Identifiable (Stage 1):** `beta_M`, `alpha_0`, `gamma_0`, `beta_V`.
- **Not identifiable from CHECKED alone:** `beta` (needs follower graph), `alpha_1`/`alpha_2` (needs stance labels), `alpha_3` (needs opinion network), reactivation shock parameters.
- `r_1_1` is known confounded (structural identifiability test).

## Train/Test Protocol

- Chronological split: first 70% of steps for fitting, final 30% for validation.
- At least 3 training steps + 1 validation step required.
- Fixed seed tuple: `(11, 23, 37, 53, 71)`.

## Required Provenance Metadata

Every replay/calibration result must record:
- `case_id`, `source_dataset`, source revision
- `network_mode`, `step_hours`
- `seeds` tuple
- `model_version`, git commit
- Parameter dictionary
- `node_count`, `interaction_count`, `truncation_count`
- Assumption flags (broadcast primary, no leakage, oracle upper-bound, latent E, latent opinion)
