## 二、对 β 校准的约束

### 2.1 β 的间接估计

从级联数据可以推导：

\[
\text{repost\_count} = N_{\text{view}} \times \beta \times \bar{k}_{\text{eff}} \times P_{\text{activate}}
\]

其中：
- repost_count: observable (shared_count)
- N_view: 帖子被看到的次数（未知）
- k̄_eff: 每个 viewer 的有效邻居数（未知）
- P_activate: 可观测代理为 σ(α₀ + α₁|ō| + ...)（可从 stance 标签估计）

**如果没有 N_view，β 不能独立识别**。但从级联规模分布可以约束 β × k̄_eff 的复合值。

### 2.2 从重复转发者占比的定性约束

96.2% 的转发者在采集的 45 个根帖子中只出现一次。这意味着跨帖重复转发行为较少（3.8% 的转发者出现在 ≥2 个根帖的转发链中）。

**注意**：不能从 3.8% 的跨帖重复率直接推导 P(E→A) ≈ 13%，因为：
- 仅采集了 45 个高热度帖子，每个用户的曝光机会不完整；
- 没有未转发的曝光者作为分母；
- 转发行为不是独立同分布（热度、内容类型、时间因素）；
- 采集覆盖率为 17-22%，存在右删失。

当前仅能定性说明：默认参数 α₀=-2.5, α₁=1.5 产生的激活概率阶数（~10-20%）与观测的重复参与水平在数量级上一致。精确的 P(E→A) 估计需要完整的曝光分母数据。

### 2.3 β 的阶数估计

假设典型微博帖子被 500-5000 人看到：
- 如果 N_view = 500：β × k̄ = 2926/(500×0.13) ≈ 45 → β 过高
- 如果 N_view = 5000：β × k̄ = 2926/(5000×0.13) ≈ 4.5
- 如果 N_view = 50000：β × k̄ = 2926/(50000×0.13) ≈ 0.45

对于 k̄ ∈ [3, 20]（reply graph 到 follower graph）：
- β ∈ [0.02, 0.15]

这确认了 **β ∈ [0.02, 0.15] 是先验合理范围**。
