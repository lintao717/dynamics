## Scientific Interpretation Limits

- CHECKED provides root-linked interactions, not a complete follower graph
- U, E, and private opinion `o` are latent
- Broadcast mode is primary; oracle_static is upper-bound sensitivity only
- Stage-1 fits only `beta_M`, `alpha_0`, `gamma_0`, `beta_V`
- `beta` cannot be separately identified from CHECKED alone
- Stance and arousal loss weights are zero (no labeled text signals)
